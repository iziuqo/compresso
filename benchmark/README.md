# Benchmark corpus

A small, license-clean image corpus for the public benchmark suite (issue
[#4](https://github.com/iziuqo/compresso/issues/4)) and the comparison figures
in the main [README](../README.md#comparison). Unlike `_assets/` (the
gitignored, personal-photo corpus used for additional local-only test
coverage — see `packages/compresso/test/browser/corpus.test.js`), everything
here is committed and meant to be shared.

| File | Format | Stresses |
|---|---|---|
| `landscape.jpg` | JPEG, 1600×1200 | high-resolution photographic content |
| `transparent-graphic.png` | PNG | alpha-channel transparency |
| `screenshot.png` | PNG, 1280×800 | text-heavy, flat-color content |
| `already-optimized.webp` | WebP | an already-efficient source (never-bigger guarantee) |
| `sample.heic` | HEIC | HEIC/HEIF input decoding |

## Provenance

Every file except `sample.heic` is **synthetic** — generated by
[`generate-benchmark-corpus.mjs`](../packages/compresso/scripts/generate-benchmark-corpus.mjs)
(gradients, shapes, and rendered text drawn to a canvas), not sourced from a
third party. That sidesteps the license/attribution question entirely: there's
no photographer to credit, and the repo's own MIT license covers these files
like any other source in it. `sample.heic` is copied from
`packages/compresso/test/fixtures/` (also synthetic) — no browser can *encode*
HEIC, so a real photo is the only way to get an authentic one.

**Open gap:** these are stand-ins, not real-world photos. Real CC0/public-domain
contributions — especially actual HEIC photos from a device, and a genuinely
high-megapixel JPEG — are still welcome per issue #4; comment there first to
agree on storage before adding anything large.

Regenerate the synthetic files (e.g. after tuning what they stress) with:

```bash
npm run generate:benchmark-corpus -w packages/compresso
```

## Usage

`packages/compresso/test/browser/benchmark.test.js` runs `compress()` against
every file here on every CI run, across Chromium/Firefox/WebKit — both as a
regression check (the never-bigger guarantee must hold) and as the source of
real before/after numbers.
