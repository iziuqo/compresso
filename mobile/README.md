# Compresso for iOS and Android

Expo (SDK 58) app built on the same never-bigger rules as compresso.js.

[![Download on the App Store](../website/public/badges/app-store/en.svg)](https://apps.apple.com/app/id6829326032)

Android is in closed testing on Google Play; its badge goes here when it reaches production.
Plan: https://claude.ai/artifact/WoSbpZ6WvuNFqR5ASPoiat

```bash
npm install
npm run web          # runs in the browser with the canvas engine
npm run ios          # needs Xcode; builds the native engine
npm run android      # needs Android Studio; builds the native engine
npm test             # plan, presets and translation-parity tests
npm run typecheck
```

## Layout

- `src/engine/plan.ts` decides quality, size targets and the long-edge fallback. It knows nothing about the platform.
- `modules/compresso-engine` is the native module: ImageIO and PhotoKit on iOS, ImageDecoder, Bitmap and MediaStore on Android. `src/engine/host.web.ts` is the browser version.
- `src/i18n/locales` holds the seven languages the website ships. `npm test` fails if a key or placeholder is missing.
- `src/app` holds the screens (Expo Router).

`ios/` and `android/` are generated by `expo prebuild` and are not committed. Change native settings in `app.json`.

## Store notes

- No photo-library read permission on either platform. Picking uses the system photo picker, and saving asks for add-only access on iOS.
- The bundle id is `xyz.izaias.compresso` on both stores. App Store id: 6829326032.
